01 / Project Idea

Making India easier to explore

Bharatyatra brings destinations, travel planning, accommodation guidance and an AI travel assistant into one simple interface.

DiscoverComparePlanSave
02 / Problem Statement

Why this project?

Scattered information

Travel details are often spread across many websites and apps.

Planning friction

Users need to compare destinations, seasons, budgets and stays quickly.

Mobile access

A tourism tool should work smoothly on laptops and phones with low resource usage.

Personal guidance

Travellers need practical itinerary, cab and accommodation suggestions.

03 / Key Features

What Bharatyatra can do

Destination discovery

Search and filter Indian destinations by experience.

Trip planner

Save destinations, dates, travellers, budget and preferences.

Travel facilities

View cab, hostel, guest-room and stay suggestions.

AI assistant

Ask for itineraries, comparisons, budgets and travel tips.

Surprise destination

Discover a random destination with one lightweight click.

Responsive UI

Use the same application on laptop, tablet or phone.

05 / System Architecture

How the application works

Browser UI→Node.js Server→REST API→JSON Database

The frontend communicates with the backend through lightweight API routes. The backend serves the website, provides travel data, handles AI requests and stores trip details.

GET /api/healthGET /api/destinationsPOST /api/aiPOST /api/trips
06 / Database

Simple, lightweight storage

No MongoDB or MySQL installation is required for the demo.

  • Trip data stored in backend/data.json
  • Trips can be created, read and deleted
  • File is created automatically
  • Atomic writes reduce corruption risk
  • Very low laptop resource usage
07 / AI Assistant

Smart travel guidance

The assistant understands natural travel questions and gives practical answers using the destination database.

Example query

“5 days Kerala trip with cab and hostel under Rs. 30000”

Example response

Itinerary, budget, cab options, stay options, best season and planning tip.

If an OpenAI key is unavailable, the local assistant continues working without external API cost.

10 / Demonstration Flow

How to use Bharatyatra

  1. Open the website in Chrome.
  2. Search or filter destinations.
  3. Open a destination to view details and facilities.
  4. Ask the AI assistant for a plan or comparison.
  5. Add destinations to My Trip Planner.
  6. Save trip dates, budget and preferences.
09 / Deployment

Run it on laptop or mobile

Start backend

node backend/srever.js

Open: http://localhost:3000

Same Wi-Fi mobile access

Use the laptop IPv4 address:

http://LAPTOP-IP:3000

The server listens on 0.0.0.0, and the AI uses same-origin requests so the app works beyond localhost.
